# Playback V3 Rehearsal Acceptance Checklist

Record build version/commit, date, operator, DVS sample rate/buffer, Dante leader, console state, and Sunday set name.

For the exact Sunday set:

- [ ] Confirm the set and exact order, arrangements, keys, transitions, and routing.
- [ ] Load each song; record any load over 10 seconds.
- [ ] Start each song and confirm stems/click/cues/grid begin together.
- [ ] Pause/resume and stop/replay without drift, stale audio, or duplicate cues.
- [ ] Jump to previous/next sections; confirm exact boundary and correct cue.
- [ ] Repeat and continue; confirm the grid and later cues remain correct.
- [ ] Change songs and verify the selected song, pad, routing, and preload state.
- [ ] Transpose applicable songs; confirm pitch changes while timing/duration do not.
- [ ] Play complete songs; confirm no late stems, dropouts, speed changes, or drift.
- [ ] Confirm every Dante stem output and PB_IEM automatic mute-follow behavior.
- [ ] Confirm audio health stays at 48 kHz / 512 with zero xruns, deadline misses, clock stalls, device errors, and PB_IEM overloads.
- [ ] Exercise Stop/Panic and Clear Fault; confirm safe, understandable recovery.

For any failure record: timestamp, song, measure/beat, preceding action, expected result, actual result, whether playback continued, audio-health display, Dante clock state, and recovery action.
